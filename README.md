# ORGA: Oxymiron Organization Investigation

Standalone research site for the Oxymiron Organization investigation, migrated from Lucerna project.

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build production site
npm run build
```

## Project Structure

- `content/` - Investigation content (Markdown files)
- `static/images/` - Static assets and images
- `config/` - Hugo configuration
- `layouts/` - Custom HTML templates
- `scripts/` - Build and validation tools
- `deploy/` - Deployment configuration

## Development

Built with Hugo static site generator and Blowfish theme. Content is written in Markdown with custom shortcodes for enhanced presentation.

## Deployment

Configured for Netlify deployment with automatic builds on push to main branch.
